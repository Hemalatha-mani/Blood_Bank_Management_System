 # Project Title :
 Blood Bank Management System

# Project Overview :
The Blood Bank Management System helps manage blood donors, blood inventory, blood requests, and blood donations efficiently. It allows blood bank staff to maintain records digitally instead of using manual registers.

 # Problem Statement : 

Many blood banks maintain donor and blood stock records manually, which can lead to:
    1.Data redundancy
    2.Difficulty in tracking blood availability
    3.Delayed response to blood requests
Errors in donor information management
This system automates the management of blood bank operations.

**Technologies Used**
Frontend : HTML,CSS,Bootstrap,React.js
Backend  : Java,Spring Boot
Database : PostgreSQL

# Project Objectives 

The main objective of the Blood Bank Management System is to develop a web-based application that automates and simplifies the management of blood bank operations, including donor records, blood inventory, donations, and blood requests.

# Specific Objectives

1.To maintain donor information efficiently
2.To manage blood inventory effectively
3.To record and monitor blood donations
4.To process blood requests quickly
5.To provide blood availability search
6.To reduce manual paperwork
7.To improve data accuracy and reliability
8.To support efficient decision-making
9.To implement CRUD operations
10.To develop a user-friendly web application

# Overall Objective

To design and develop a secure, efficient, and user-friendly Blood Bank Management System that automates blood bank operations, improves blood inventory management, and ensures timely access to blood-related information through a web-based platform.

# User Identification

The Blood Bank Management System will have the following users:

**Admin**
1.Manages the entire system.
2.Maintains donor records.
3.Monitors blood inventory.
4.Handles blood requests.
5.Generates reports.

**Staff**
1.Registers donors.
2.Updates blood stock details.
3.Records blood donations.
4.Processes blood requests.

# Module Identification

Module 1: User Authentication
Module 2: Donor Management
Module 3: Blood Inventory Management
Module 4: Donation Management
Module 5: Blood Request Management
Module 6: Dashboard
Module 7: Reports Management
